📡 Configuración Oficial del Webhook

Recomendado

Registra estos datos en tu Panel de Factus Pay > Sección Webhook para recibir confirmaciones de pago automáticas en tiempo real:

1. URL del Webhook:
http://localhost:3000/api/factus/webhook
2. Llave Secreta (key):
factus_whsec_7d9e4a1b8c2f530691e84a2d67c50b3e
3. URL Completa con Query:
http://localhost:3000/api/factus/webhook?key=factus_whsec_...
💡 Requisitos del Webhook según la documentación oficial:
  • HTTPS Público: Factus Pay requiere una URL accesible por internet. En desarrollo local usa ngrok (ej: ngrok http 3000) o Cloudflare Tunnel.
  • Validación Segura: Tu backend valida la llave en query string ?key=... con crypto.timingSafeEqual y responde 401 si no coincide.
  • Tiempo de Respuesta: Tu servidor responde 200 OK en menos de 10 segundos para confirmar la entrega y evitar reintentos.
  • Idempotencia: Se utiliza el reference_code como clave única para no procesar pagos duplicados.
